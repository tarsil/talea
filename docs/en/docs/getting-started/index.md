# Getting started

This path teaches the smallest useful Talea workflow before introducing its
advanced contract vocabulary.

1. [Why Talea?](why-talea.md) explains the product boundary.
2. [Installation](installation.md) covers released and source checkouts.
3. [Five-minute quickstart](quickstart.md) defines, validates, parses, serializes,
   and projects one Spec.
4. [Tutorial](tutorial.md) grows the same ideas into nested and constrained data.
5. [Production service boundary](production-service.md) handles hostile bytes
   without depending on a web framework.

Python 3.14 or newer is required.
